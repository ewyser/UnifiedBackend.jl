API Reference

Platforms

UnifiedBackend.Platform — Type
Platform(kind, platform, brand, name, backend, arraytype, handle)
Platform(; kind=:device, platform, brand="", name=string(platform), backend, arraytype, handle=nothing)

A place where kernels run: kind :host (a CPU) or :device (a GPU); its platform (:CPU, :CUDA, :ROCm, …), brand and name; the KernelAbstractions backend that runs kernels there (CPU(), CUDABackend(), …); the arraytype that holds data there (Array, CuArray, …); and the native handle a device is activated with (nothing for a host).

source
UnifiedBackend.host_platforms — Function
host_platforms() -> Vector{Platform}

The registered hosts: the CPU, registered when the package loads.

source
UnifiedBackend.device_platforms — Function
device_platforms() -> Vector{Platform}

The registered devices (GPUs), in registration order: none unless a GPU package's extension (CUDA.jl, AMDGPU.jl) found a working GPU, or a platform was added with register!.

source
UnifiedBackend.register! — Function
register!(platform) -> platform

Add a platform to the registry: to host_platforms() or device_platforms(), by its kind.

source

Selecting and activating

UnifiedBackend.select_platform — Function
select_platform(which="host") -> Platform

The platform to run on: "host", the host (the CPU); "device", the first registered device (a GPU), or the host when there is none, which it says.

source
UnifiedBackend.activate! — Function
activate!(platform) -> platform

Make platform the current device of its GPU package (CUDA.device!, AMDGPU.device!, from the extensions' activate!(handle) methods); a host has nothing to activate.

source

For extensions and tests

UnifiedBackend.register_gpus! — Function
register_gpus!(platform, brand, backend, arraytype, handles, name) -> device_platforms()

Register one device per native handle (name(handle) its name): what a GPU package's extension calls when it loads and the GPU works (CUDAExt, ROCmExt).

source
UnifiedBackend.host_platform — Function
host_platform(arch=Sys.ARCH, model=<this CPU's model>) -> Platform

The host: a CPU of any architecture and brand (its brand "unknown" when the model names none of HOST_BRANDS[arch], its name the architecture when the model is unknown), run by KernelAbstractions' CPU() on Arrays.

source
UnifiedBackend.host_brand — Function
host_brand(model, brands) -> String

The first of brands that the CPU model string names, else "unknown".

host_brand("Intel(R) Core(TM) i5-1038NG7", ["Intel(R)", "AMD"])  # "Intel(R)"
host_brand("Apple M2", ["Intel(R)", "AMD"])                     # "unknown" (x86_64 Julia under Rosetta)
